# 作品库现状：风格、界面功能与未来规划

记录日期：2026-09-16，对应提交 `1ff414c`。改动风格或功能后请同步更新本文。

## 一、页面与风格

| 页面 | 地址 | 风格 | 要点 |
| --- | --- | --- | --- |
| 首页 | `/` | 千禧幻彩（Y2K） | 粉紫渐变底加紫色点阵；「Works」镀铬渐变标题，只在红与酷粉之间变化；圆角玻璃卡片。不用星星、爱心点缀 |
| Archive 列表页 | `/archive/` | 日系图文 | 黑白红配色，Bungee 粗体大字，带黑边的微倾卡片，底部构成主义印章 |
| PINK 分区页 | `/pink/` | 地雷系外框 + 海报画面 | 粉色格纹底、哥特黑体标题、蝴蝶结、蕾丝、缝线虚线；主卡片画面还原 PINK NOISE 海报 |
| 作品页 | `/archive/<id>/`、`/pink/noise/` | 各作品自身风格 | 外壳只加一个「目录」按钮和导航浮层（日系图文） |
| 404 | 其他地址 | 外壳默认 | 「这件作品不在这里」 |

## 二、界面功能

### 全站

- **单页路由**：用 History API 切换页面，支持浏览器前进后退；普通页面切换带 View Transitions 过渡，不支持的浏览器直接切换。
- **加载动画**：进入首页或分区时播放，动画遮住页面期间完成渲染，揭开时页面入场动画才开始。

  | 进入 | 风格 | 编排 | 时长 |
  | --- | --- | --- | --- |
  | 首页 | 千禧幻彩 | 镭射光盘旋转，镀铬「Works」刷出，糖果条纹进度条走满，从光盘中心圆形揭开 | 约 2.1 秒 |
  | Archive | 日系图文 | 黑白两块斜切撞合，速度线转动，大字逐字落章，数字 00→06，红色斜杠进度，沿斜线上下分开 | 约 1.7 秒 |
  | PINK | 地雷系 | 蕾丝格纹幕布合拢，缝线名牌里爱心灌满，NOW LOADING 百分比，浮出「Pink Noise」，幕布拉开 | 约 2.0 秒 |

  播放规则：从别处进入首页或分区时都播放，包括直接打开、刷新、浏览器前进后退；在同一分区里列表和作品之间切换不播放；直接打开作品页不播放（作品页有自己的加载画面）。
- **减弱动效**：系统开启「减少动态效果」时，关闭所有动画、加载动画和视差，内容直接完整显示。
- **触摸设备**：悬停效果改由触摸触发，手指按下时出现、松开即消失；手机倾斜会驱动卡片视差（iOS 首次触摸时请求授权）。
- **磁吸**：WORKS 标志、顶部导航链接、「目录」按钮会轻微跟随鼠标（仅鼠标设备）。
- **其他**：「跳到作品」键盘链接；旧书签 `/#tomo` 这类地址自动转到 `/archive/tomo/`。

### 首页

- 分区卡片由 `library.js` 的 `collections[]` 生成。桌面三列，1000px 以下两列，650px 以下一列；封面固定 4:3，封面里的文字随卡片宽度缩放。
- 卡片交互：
  - 发光高光跟随指针，位于角色后方，形成背光。
  - 角色随指针视差移动。
  - Archive 封面的八边形圆盘旋转放大；PINK 封面的方形线框转到 45°。
  - 进入按钮被指针磁吸，并伸出液滴；按下时卡片微缩。
- 卡片滚动到可见时依次淡入。
- 网格末尾有一张 COMING SOON 占位卡：编号按分区数自动递增，不可点击，也没有悬停效果。

### Archive 列表页

- 六张作品卡由 `works[]` 生成，滚动到可见时带轻微旋转淡入。
- 悬停或触摸时，卡片阴影染上作品主色，角色放大上移，背景几何线旋转，「打开作品」玻璃标签出现（手机上常显）；鼠标移动时角色有视差。
- 底部构成主义印章缓慢旋转。

### PINK 分区页

- PINK NOISE 主卡片（桌面占两列）：悬停或触摸时，三位角色向外微移，挂件和八边形转动，蝴蝶结歪一下，ENTER 按钮变热粉且爱心跳动。
- Coming Soon 卡（WORK 02）：黑底格纹、爱心锁、闪烁光标，不可点击。
- 桌面两列（2:1），650px 以下一列。

### 作品页

- 用 iframe 装载作品，加载时显示编号、标题和进度条；30 秒仍未打开会显示「重试」和「返回作品库」。
- 左上角「目录」按钮打开导航浮层：返回首页、两个分区及其作品列表，当前作品高亮；在作品里按 Esc 也能打开。
- 浏览器地址栏主题色跟随当前作品。

## 三、未来规划与待办

### 已确定的方向

- 作品库会继续导入更多分区。首页排版和数据结构已按可扩展设计，COMING SOON 卡会自动顺延到最后。
- PINK 分区预留了下一件作品的位置（WORK 02 Coming Soon）。

### 待决定

- 外壳风格是否统一：首页已是千禧幻彩，Archive 列表页和「目录」浮层还是日系图文。统一还是保留这种反差，尚未决定。

### 可改进项（技术观察，尚未排期）

- 首次打开要等 Google Fonts 样式表加载完，脚本才执行，大约有 0.6 秒空白才出现加载动画。可以改为非阻塞加载字体，或精简字重。
- 全局样式 `button,a{outline:none}` 去掉了键盘焦点框，用键盘浏览时看不到当前位置。
- 一些数量是写死的文案，增删作品或分区时要一起改：Archive 页的「06」「六种对话」，Archive 加载动画的「构成主义 · 六件作品」，首页的「SELECTED INTERACTIVE WORKS / 01—02」，页脚的「02 COLLECTIONS · 07 WORKS」，PINK 页的「03」。
- `index.html` 里的 `#transition` 是旧的过场元素，已不再使用。

### 新增一个分区的步骤

1. `library.js`：在 `collections[]` 加一条。有专属封面构图就写 `art` 函数；没有就给 `image`，自动使用默认单图卡片。
2. 写分区页模板，加进 `route()`、`render()`、顶部导航和「目录」浮层；在 `areaOf()` 里注明该分区作品页的归属，加载动画的播放规则依赖它。
3. 需要加载动画时，在 `loaders` 里加一项，并在 `index.html`、`library.css` 加对应结构和样式。
4. 在 `server.mjs` 的 `shellRoutes` 和 `scripts/check.mjs` 的路由列表加上新地址。
5. 封面图转成 WebP 放进 `public/covers/`（quality 92、原尺寸），并在 CLAUDE.md 记录来源。
6. 更新上面列出的写死数量文案。
7. 跑 `npm run check`，并在浏览器里实际打开新分区、首页和一个作品页确认。
