# AFTERGLOW artwork

Generated with the built-in image generation tool from the supplied photographer reference. Only the foreground character was used. AFTERGLOW is a presentation title, not an asserted identity.

Prompt set:
1. Full-length faceless low-poly geometric character, black bob, warm ivory cardigan, navy sailor collar, muted teal neckerchief, charcoal knee-length pleated skirt, dark socks and loafers, vintage camera held below chin; complete silhouette and generous margins.
2. Same character, shy three-quarter stance, lowered tilted head, camera close to chest, elbows tucked, knees close and one foot drawn back.
3. Preserve each pose exactly; replace the incorrectly generated checkerboard with uniform magenta for production keying.
4. Preserve canvas and pose; remove scarf/skirt and reconstruct opaque blouse and modest shorts underneath for animation coverage.

The attempted layer sheet was rejected because its pieces did not register accurately. The final skirt/scarf were isolated directly from each keyed master at unchanged coordinates. Reconstructed base pixels were used only beneath those pieces. Registration marks were removed from the outer margins. All delivered WebP assets contain actual alpha; no checkerboard is used as transparency. Lossless WebP preserves the generated 1024 x 1536 resolution.

Assets: public/characters/afterglow/assets/{a,b}-{master,base,skirt,scarf}.webp.
